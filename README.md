# 篠澤広 Bot 利用ガイド

Discordで動作する、篠澤広をイメージした会話Botの使い方をまとめています。

Botにメンションして話しかけると、AIが会話内容に応じて返答します。会話履歴や登録した記憶、散歩記録などを利用する機能もあります。

## 基本的な使い方

Botが参加しているDiscordサーバーで、メッセージにBotをメンションして話しかけてください。

```text
@篠澤広 おはよう
@篠澤広 今日も頑張ろう
@篠澤広 今日は少し疲れた
```

Botがオンラインで、チャンネルの閲覧・メッセージ送信権限を持っていれば応答します。

### 利用時のポイント

- 基本的に、メッセージ内でBotへのメンションが必要です。
- AIの応答生成には少し時間がかかる場合があります。
- 会話の内容によって返答の長さや表現が変わります。

## 主な機能

### AIとの会話

メンションしたメッセージに対して、AIが会話形式で返答します。

挨拶や日常会話のほか、質問や相談にも対応します。ただし、AIの回答が常に正確とは限りません。重要な情報は別の情報源でも確認してください。

### 長期記憶

今後の会話でも参照したい情報を、長期記憶として登録できます。

```text
@篠澤広 覚えて: 私はイラストを描くのが好き
```

登録した内容は、以後の会話で返答の参考として使われる場合があります。

- 通常の会話履歴と長期記憶は別々に扱われます。
- 登録する内容は、後から参照してほしい情報に絞ることをおすすめします。
- 記憶の修正・削除方法は、Botの現在の実装や管理者の案内を確認してください。

### 散歩記録

歩数や距離をメッセージで伝えると、散歩記録として保存できます。

**歩数を記録する例**

```text
@篠澤広 今日は5000歩歩いたよ
```

**記録を確認する**

```text
@篠澤広 今日の記録
@篠澤広 最近の記録
```

距離を入力していない場合、歩数から概算距離を計算する設定が使われることがあります。概算値は実際の歩幅とは異なる場合があります。

> **注意：** 同じ歩数を複数回送った場合の扱いは、現在の記録処理の実装に依存します。重複登録を避けたい場合は、同じ記録を繰り返し送らないでください。

### 口調・返答スタイル

会話から口調の候補を抽出し、確認して採用することで、Botの返答の雰囲気を調整できます。また、理想の返答を口調サンプルとして手動登録したり、返答の長さや避けたい表現などを返答スタイルとして設定したりできます。

以下のコマンドは、すべてBotへのメンションを付けて送信してください。

#### 口調候補の確認

```text
@篠澤広 口調候補
```

過去の会話から新しい候補を抽出し、確認待ちの候補を最大10件表示します。候補にはID、ユーザーの発言、Botの返答が表示されます。

**候補を採用する**

```text
@篠澤広 口調採用: 1
```

**候補を却下する**

```text
@篠澤広 口調却下: 1
```

`1` は「口調候補」に表示された候補IDに置き換えてください。

#### 口調サンプルの手動登録

ユーザーの発言と理想の返答を `|` で区切って登録します。`口調例` と `口調修正` のどちらも使用できます。

```text
@篠澤広 口調例: おはよう | ……おはよう、プロデューサー。
@篠澤広 口調修正: おはよう | ……おはよう、プロデューサー。
```

#### 返答スタイルの登録

```text
@篠澤広 返答スタイル: 文中に不自然な読点を入れず、自然な文章にする
```

次の言い方も登録コマンドとして利用できます。

```text
@篠澤広 こういう風に回答して: 短く自然な文章で返答する
@篠澤広 こういうふうに回答して: 短く自然な文章で返答する
@篠澤広 こういう風に返答して: 短く自然な文章で返答する
@篠澤広 こういうふうに返答して: 短く自然な文章で返答する
@篠澤広 今のソースにこう返して: 短く自然な文章で返答する
```

返答スタイルは1000文字以内で登録してください。

#### 返答スタイルの一覧

```text
@篠澤広 返答スタイル一覧
```

登録済みの返答スタイルとIDを確認できます。

**返答スタイルの修正**

```text
@篠澤広 返答スタイル修正: 1 | 文中に不自然な読点を入れず、自然な文章にする
```

**返答スタイルの削除**

```text
@篠澤広 返答スタイル削除: 1
```

修正・削除の `1` は「返答スタイル一覧」に表示されたIDに置き換えてください。

#### 補足

- 口調候補の採用・却下には「口調候補」に表示された候補IDを指定してください。
- 返答スタイルの修正・削除には「返答スタイル一覧」に表示されたIDを指定してください。
- 口調サンプルと返答スタイルは別々に保存されます。
- 登録内容はAIが返答を生成する際の参考として使われますが、すべての返答に必ず反映されるわけではありません。

## 今後追加を検討している機能

以下は今後の拡張候補であり、現時点で利用できる機能として案内するものではありません。

- **Web検索：** Botが知らない作品・人物・技術情報などを質問された際にWeb検索し、情報源を添えて要約する機能。
- **過去の会話を踏まえた話題の再利用：** 過去の会話を要約して保存し、関連する話題を後日の会話で参照する機能。
- **予定・リマインダー：** 予定の登録・一覧・削除と、指定時刻にDiscordへ通知する機能。

機能が実装された際は、このREADMEも更新します。

## うまく動かないときは

### Botが返事をしない

次の点を確認してください。

1. Botがオンラインになっているか。
2. メッセージ内でBotをメンションしているか。
3. Botにチャンネルの閲覧権限とメッセージ送信権限があるか。

### 返答に時間がかかる

AIモデルの読み込み状態や、Botを動かしているPCの負荷によって応答時間が変わります。時間がかかる状態が続く場合は、Botの稼働状況を管理者に確認してください。

### 以前の会話を覚えていない

通常の会話履歴と長期記憶は別の機能です。後の会話でも参照してほしい情報は、長期記憶として登録してください。

### 記録や記憶を修正・削除したい

利用者向けの操作方法が用意されていない場合は、Bot管理者に相談してください。

## 注意事項

- AIの返答には誤りが含まれる場合があります。正確性が重要な内容は、公式サイトなどの一次情報で確認してください。
- 個人情報、パスワード、認証コードなど、他人に知られて困る情報をBotに送らないでください。
- Botの機能やコマンドは開発中に変更される場合があります。利用できない操作がある場合は、管理者に確認してください。
- このREADMEは利用者向けの説明書です。Botの内部設定や管理用コマンドは掲載していません。
